# v0.1 – GitHub Hub Initialized

## 🇧🇷 Notas de lançamento (pt-BR)

Esta versão cria a base da "hub" GitHub do projeto **Shantilly**:

- Estrutura completa de issues, labels, milestones e Projects.
- Workflows de CI/CD, relatórios e integração com IA.
- Documentação inicial do fluxo de contribuição e colaboração híbrida (humanos + IA).

### Principais entregas

- Issues estruturadas por épicos e waves.
- Templates de issue e PR.
- Labels hierárquicas (priority, type, area, status).
- Milestones v1.0/v2.0 definidas.
- Project "Shantilly Roadmap" configurado.
- Workflows para:
  - Auto-labeling.
  - Relatórios semanais.
  - Integração com IA.
- Wiki expandida, README atualizado e GitHub Pages configurado.
