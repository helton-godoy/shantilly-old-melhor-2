# Shantilly

**Runtime TUI declarativo moderno para criar interfaces de terminal interativas usando YAML.**

## 🚀 Início Rápido

```yaml
# exemplo.yaml
title: "Bem-vindo ao Shantilly"
fields:
  - name: "nome"
    label: "Seu nome"
    type: "input"
  - name: "email"
    label: "Email"
    type: "input"
```

```bash
shantilly --file exemplo.yaml > output.json
```
