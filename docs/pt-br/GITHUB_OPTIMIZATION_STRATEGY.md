## 📁 Estrutura de Arquivos Implementada

```

├── workflows/

│   └── weekly-report.yml       # Relatórios semanais

```

## 🤖 Integração IA-Humanos

### Automatizações Implementadas
1. **Auto-labeling**: Baseado em conteúdo e palavras-chave
2. **Relatórios Semanais**: Métricas de progresso automáticas
3. **Dependabot**: Updates de dependências automatizados

### Padrões para Colaboração IA
- Labels específicos: `team::ai`, `team::human`, `team::mixed`
- Templates estruturados com campos padronizados
- Workflows que facilitam review e merge automatizado
