# Monitoramento GitHub – Shantilly (pt-BR)

Este documento define **como monitorar saúde e adoção** do repositório Shantilly usando recursos nativos do GitHub.

## 1. Insights principais

Use a aba **Insights** do repositório para revisar periodicamente:

- **Issues**
  - Abertas vs fechadas por período.
  - Tempo médio para fechamento.
- **Pull Requests**
  - PRs abertas vs fechadas/mergiadas.
  - Tempo médio até merge.
- **Contributors**
  - Número de contribuidores ativos por semana/mês.

## 2. Monitoramento de adoção (4.2)

Acompanhar:

- **Stars** ao longo do tempo.
- **Forks** criados.
- **Número de contribuidores únicos**.

Sugestão de rotina:

- A cada **sprint** (semanal ou quinzenal):
  - Registrar rapidamente: stars, forks, contribuidores ativos.
  - Comparar com o sprint anterior.

## 3. Rotina recomendada

1. No fim de cada sprint:
   - Abrir **Insights → Issues / Pull requests / Contributors**.
   - Anotar métricas em um comentário de issue de retrospectiva ou em um doc próprio.
2. Na planning do próximo sprint:
   - Usar esses dados para ajustar prioridades do Project "Shantilly Roadmap".
