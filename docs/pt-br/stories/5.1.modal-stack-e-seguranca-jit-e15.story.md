# Story E1.5 — Modal Stack + Segurança JIT (`confirm` / `prompt_secrets`)

Como autor de aplicações no Runtime TUI Declarativo,  
Eu quero que confirmações e coleta de segredos ocorram via uma Modal Stack única e governada,  
Para que ações sensíveis usem confirmação Just-In-Time com isolamento, foco correto e proteção de segredos.

## Escopo

- Implementar Modal Stack como mecanismo único de sobreposição interativa.
- Localização exclusiva da implementação: `internal/runtime/modal/**`.
- Integração obrigatória com:
  - [`LayoutManager`](internal/runtime/layout/manager.go:1) para desenhar apenas o modal do topo sobre o layout base.
  - [`EventManager`](internal/runtime/event/manager.go:1) para:
    - Abrir modais via `ModalRequest`,
    - Roteá-los como `ShantillyEvent` de resposta,
    - Continuar o fluxo `on:` após confirmação/preenchimento.

## Regras Normativas (Invioláveis)

- Estrutura:
  - Modal Stack explícita (`push` / `pop` / `top`).
  - Apenas o topo recebe foco e eventos.
  - Enquanto houver modal ativo:
    - Interação com plano de fundo bloqueada.
- Abertura de modais:
  - Sempre via pipeline:
    - `ShantillyEvent` → `EventManager` → `on:` → `ModalRequest` → Modal Stack.
  - Proibidos modais soltos em componentes, LayoutManager ou código legado.
- Segurança JIT:
  - `RunAction.Confirm: true`:
    - DEVE abrir modal de confirmação antes de executar `run:`.
  - `RunAction.PromptSecrets`:
    - DEVE abrir modal(is) dedicado(s) para segredos.
  - Segredos:
    - Apenas em memória, nunca logados, nunca persistidos.
    - Usados apenas para compor `RunAction` final no lado seguro.
- Integração com ScriptRunner:
  - Após confirmação/suprimento de segredos:
    - `EventManager` monta `RunAction` final e delega ao ScriptRunner.
  - Nenhum atalho direto Modal → ScriptRunner, sempre via `EventManager` + `on:`.

## Critérios de Aceite

- Qualquer `confirm` ou `prompt_secrets` configurado em `run:`:
  - Gera `ModalRequest` via `on:`; nenhuma execução ocorre sem resolução do modal.
- Em presença de múltiplos modais:
  - Apenas o topo responde; fechamento restaura corretamente o contexto anterior.
- Verificações de segurança:
  - Nenhum segredo aparece em logs, eventos externos ou arquivos.
- Governança:
  - Gate QA `docs/qa/gates/1.x.modal-stack.yml` garante:
    - Uso exclusivo da Modal Stack,
    - Foco correto,
    - Integração com Segurança JIT.
