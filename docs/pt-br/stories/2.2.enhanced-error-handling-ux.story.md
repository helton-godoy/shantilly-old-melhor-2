# Story 2.2: Enhanced Error Handling & UX

## Story

**Como um** usuário do runtime TUI declarativo,
**Eu quero** feedback claro de erros, ajuda contextual e indicadores de progresso sobre os componentes declarados no YAML único,
**Para que** eu consiga completar fluxos definidos declarativamente, com correção guiada, sem dependência de comportamentos ad hoc do v1.x.

## Acceptance Criteria

1. Validation errors display prominently with clear messages
2. Users can easily correct validation errors
3. Help text provides guidance for complex fields
4. Progress indicators show form completion status
5. Keyboard shortcuts improve navigation efficiency

```go

    // Existing fields...
    errors      map[string]string  // field key -> error message

    completed   map[string]bool    // field key -> completion status

}
```

### Component Specifications

**Error Display Components:**

- Mensagens de erro em vermelho itálico abaixo dos campos
- Destaque visual para campos com erro (borda vermelha)
- Ícones ou indicadores visuais para estados de erro

**Help Text System:**

- Texto de ajuda exibido abaixo dos campos quando solicitado
- Atalho de teclado para mostrar/ocultar ajuda
- Integração com o sistema de layout existente

**Progress Indicators:**

- Barra de progresso mostrando campos completados/total
- Porcentagem de conclusão exibida
- Atualização em tempo real conforme campos são preenchidos
