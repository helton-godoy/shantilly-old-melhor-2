# Story Cross-cutting — Encapsulamento Seguro do Legado (`FormComponent`)

Como mantenedor do Runtime TUI Declarativo,  
Eu quero que todo o código v1.x (FormConfig, shantilly form, internal/tui) exista apenas como implementação interna de um `FormComponent` legado,  
Para que não haja regressão ao modelo antigo nem rotas paralelas fora do pipeline declarativo.

## Escopo

- Definir o `FormComponent` (`type: form`) como ÚNICO ponto de entrada para legado v1.x.
- Confinar:
  - `FormConfig`,
  - `internal/tui/**`,
  - qualquer fluxo “shantilly form”
  exclusivamente ao sandbox interno do `FormComponent`.
- Integrar o `FormComponent` como um `ShantillyComponent` padrão do LayoutManager.

## Regras Normativas (Invioláveis)

- Contrato externo:
  - `FormComponent` é configurado via `AppConfig` v2.0 (`Component.Props`), não expõe `FormConfig` diretamente.
  - Qualquer mapeamento `Props` → estruturas antigas é DETALHE INTERNO.
- Eventos:
  - Toda interação do legado emite apenas `ShantillyEvent` (ex.: `form_id:submit`, `form_id:change`).
  - Toda automação disparada a partir do legado passa por:
    - [`EventManager`](internal/runtime/event/manager.go:1) + `on:` + (`RunAction` | `ModalRequest` | `UpdateState`).
- Proibições:
  - Proibido usar `FormConfig` ou `internal/tui` diretamente em novos fluxos.
  - Proibido abrir modais ou executar scripts diretamente no código legado:
    - Sempre via `on:` + Modal Stack + ScriptRunner.
  - Qualquer uso de v1.x fora do `FormComponent` é bug arquitetural.

## Critérios de Aceite

- Todo YAML e docs ativos:
  - Referem-se apenas ao runtime declarativo como baseline; v1.x marcado explicitamente como `legacy`.
- Implementação:
  - `FormComponent` integrado ao LayoutManager como componente comum.
  - Código v1.x só é importado/usado dentro do módulo do `FormComponent`.
- QA/Governança:
  - Gate `docs/qa/gates/1.x.legacy-formcomponent-encapsulation.yml`:
    - Scans garantindo que `FormConfig`/`internal/tui` não sejam usados fora do sandbox.
    - Verificação de que eventos/efeitos do legado respeitam o pipeline central.
