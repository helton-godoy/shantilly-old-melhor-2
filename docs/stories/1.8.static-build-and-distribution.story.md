# Story 1.8: Static Build and Distribution

## Story

**Como um** responsável pelo runtime TUI declarativo,
**Eu quero** um processo de build que gere binários estáticos e cross-compilados para as plataformas alvo,
**Para que** o binário único `shantilly` possa ser distribuído com segurança e consistência como host do YAML declarativo.
**Pré-requisitos:** Story 1.1

## Acceptance Criteria

1. AC1: O `Makefile` (ou script de build) DEVE incluir targets para compilar o binário `shantilly`.
2. AC2: O processo de build DEVE usar flags (`CGO_ENABLED=0`, `ldflags="-s -w"`) para garantir um binário estático e otimizado.
3. AC3: Targets (ou script) DEVEM existir para cross-compilar o binário para Linux (amd64, arm64), macOS (amd64, arm64) e Windows (amd64).
4. AC4: Os binários gerados DEVEM ser executáveis em suas respectivas plataformas (verificação básica).
