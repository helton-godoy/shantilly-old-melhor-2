# Story 1.5: Navegação e Interação por Teclado

## Status

Done ✅

## Story

**Como um** usuário do shantilly,
**Eu quero** navegar entre os campos do formulário e interagir com eles usando apenas o teclado,
**Para que** eu possa preencher o formulário de forma eficiente.
**Pré-requisitos:** Story 1.4

## Acceptance Criteria

1. AC1: A tecla `Tab` DEVE mover o foco para o próximo campo do formulário.
2. AC2: `Shift+Tab` DEVE mover o foco para o campo anterior.
3. AC3: `Enter` DEVE confirmar a seleção em campos como `Select` e `Confirm`, ou mover para o próximo campo em `Input`/`Textarea` (comportamento padrão do `huh`).
4. AC4: `Space` DEVE alternar a seleção em campos `MultiSelect`.
5. AC5: As teclas de seta (Up/Down) DEVEM permitir navegação dentro das opções de campos `Select` e `MultiSelect`.
6. AC6: O campo atualmente focado DEVE ser visualmente destacado.
