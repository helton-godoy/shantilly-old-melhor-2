# Story 1.3: LayoutManager — Layout hierárquico declarativo (column/row/box)

## Story

**Como um** usuário e autor de YAML do Runtime TUI Declarativo,
**Eu quero** que o runtime consuma o `AppConfig.Layout` (LayoutNode) e construa um layout hierárquico usando `column`, `row` e `box`, instanciando componentes declarativos (`ShantillyComponent`) nas regiões corretas,
**Para que** o layout da aplicação seja totalmente definido pelo YAML único, sem lógica imperativa acoplada e alinhado ao `LayoutManager` como root model TEA.

## Acceptance Criteria

1. AC1: O runtime DEVE consumir `AppConfig.Layout` (LayoutNode) como fonte única de layout (column/row/box), sem contratos paralelos.
2. AC2: O `LayoutManager` DEVE construir uma árvore interna de layout a partir de `LayoutNode`, respeitando:
   - `type: column|row|box`,
   - `flex`, `width`, `height` quando fornecidos,
   - associação `box.component` → `Component.ID` existente.
3. AC3: O `LayoutManager` DEVE instanciar apenas componentes que implementem `ShantillyComponent`, sem executar `run:` ou qualquer automação.
4. AC4: O `LayoutManager` DEVE gerenciar foco global entre componentes focáveis, encaminhando mensagens (`tea.Msg`) somente para o componente atualmente focado.
5. AC5: O `LayoutManager` DEVE lidar com `tea.WindowSizeMsg`, recalculando bounds de forma determinística (base para comportamento “flicker-free”).
6. AC6: O desenho do layout DEVE ser totalmente derivado do YAML único (AppConfig), sem uso de estruturas de configuração legadas (`FormConfig`) como contrato público.
7. AC7: A implementação DEVE residir em `internal/runtime/layout/...` e referenciar explicitamente E1.1 nos comentários/docblocks.

func (m Model) Init() tea.Cmd {

}

func (m Model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
    switch msg := msg.(type) {
    case tea.KeyMsg:
        switch msg.String() {
        case "ctrl+c", "esc":
            return m, tea.Quit
        }
    }
    return m, nil
}

func (m Model) View() string {
    return lipgloss.NewStyle().
        Border(lipgloss.RoundedBorder()).
        BorderForeground(lipgloss.Color("63")).
        Padding(1, 2).
        Render("Shantilly TUI")
}
