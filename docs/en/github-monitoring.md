# GitHub Monitoring – Shantilly (en)

This document describes **how to monitor repository health and adoption** for Shantilly using native GitHub features.

## 1. Key Insights views

Use the repository **Insights** tab to periodically review:

- **Issues**
  - Open vs closed over time.
  - Average time to close.
- **Pull Requests**
  - Open vs closed/merged PRs.
  - Average time to merge.
- **Contributors**
  - Number of active contributors per week/month.

## 2. Adoption monitoring (4.2)

Track:

- **Stars** over time.
- **Forks** created.
- **Unique contributors**.

Suggested routine:

- At the end of each **sprint** (weekly or bi-weekly):
  - Quickly log stars, forks, and active contributors.
  - Compare with the previous sprint.

## 3. Recommended cadence

1. At the end of each sprint:
   - Open **Insights → Issues / Pull requests / Contributors**.
   - Record metrics in a retrospective issue or a dedicated doc.
2. During the next sprint planning:
   - Use these numbers to adjust priorities in the "Shantilly Roadmap" Project.
