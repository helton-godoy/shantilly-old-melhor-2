# v0.1.0 – GitHub Hub Initialized

## 🌍 Release notes (en)

This release sets up the GitHub "hub" for the **Shantilly** project:

- Complete structure of issues, labels, milestones and Projects.
- CI/CD workflows, reports and AI integration.
- Initial documentation for contribution flow and hybrid collaboration (humans + AI).

### Key highlights

- Issues structured by epics and waves.
- Issue and PR templates.
- Hierarchical labels (priority, type, area, status).
- v1.0/v2.0 milestones defined.
- "Shantilly Roadmap" Project configured.
- Workflows for:
  - Auto-labeling.
  - Weekly reports.
  - AI integration.
- Expanded Wiki, updated README and configured GitHub Pages.
